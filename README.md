# Login Page

A simple, responsive HTML login page with a clean and minimal design.

## Features

- Username input field
- Password input field
- Required form validation
- Centered login card layout
- Responsive viewport configuration
- Styled login button with hover effect
- Form submission using the `POST` method

## Preview

The page displays a centered login form containing:

1. Username field
2. Password field
3. Login button
